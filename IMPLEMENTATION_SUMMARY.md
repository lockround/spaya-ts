# Spaya TypeScript Library - Implementation Summary

## Overview

This document provides a comprehensive summary of the TypeScript implementation of the Spaya retrosynthesis-scoring API client library, rewritten from the original Python `pyspaya` library.

## Architecture Design

### Base Client (`SpayaClient`)

The abstract base class provides:
- Common HTTP request handling using `fetch` API
- Shared state management for SMILES tracking
- Result processing and status management
- Utility methods for parameter conversion
- Retry logic and error handling

### REST Client (`SpayaClientREST`)

Synchronous client optimized for:
- Batch processing of large SMILES datasets
- Rate-limited API calls with configurable intervals
- Progress tracking with optional callbacks
- Simple Promise-based interface

### Async Client (`SpayaClientAsync`)

Real-time streaming client featuring:
- WebSocket connections with auto-reconnection
- Async generators for result streaming
- Cross-platform WebSocket support
- Non-blocking operations with async/await

### Callback Client (`SpayaClientCallback`)

Event-driven client providing:
- Real-time result callbacks as data arrives
- Error handling callbacks for robust applications
- Background processing with automatic result handling
- Clean shutdown and resource management

## Usage Examples

### REST Client Example

```typescript
import { SpayaClientREST, BearerToken } from 'spaya-ts';

const client = new SpayaClientREST({
  url: 'https://spaya.ai',
  authorization: new BearerToken('your-token')
});

const results = await client.scoreSmiles(['O=C1CCCCO1', 'O=C1CCCNN1']);
console.log(results);
```

### Async Client Example

```typescript
import { SpayaClientAsync, BearerToken } from 'spaya-ts';

const client = new SpayaClientAsync({
  url: 'https://spaya.ai',
  authorization: new BearerToken('your-token')
});

await client.connect();
await client.startRetrosynthesis(['O=C1CCCCO1', 'O=C1CCCNN1']);

for await (const [smiles, result] of client.consume()) {
  console.log(`${smiles}: ${result.rscore}/${result.nbSteps}`);
}

await client.close();
```

### Callback Client Example

```typescript
import { SpayaClientCallback, BearerToken } from 'spaya-ts';

const client = new SpayaClientCallback({
  url: 'https://spaya.ai',
  authorization: new BearerToken('your-token'),
  resultCallback: async (smiles, result) => {
    console.log(`Result: ${smiles} -> ${result.rscore}`);
  }
});

await client.connect();
await client.startRetrosynthesis(['O=C1CCCCO1', 'O=C1CCCNN1']);
await client.waitResult();
await client.close();
```

## Migration from Python

Key differences when migrating from the Python library:

1. **Import Style**: ES6 imports instead of Python imports
2. **Async Patterns**: Promise-based instead of Python async/await
3. **Type Safety**: Full TypeScript type checking
4. **Error Handling**: Structured error classes with proper inheritance
5. **Configuration**: Object-based configuration instead of keyword arguments
